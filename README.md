A [make.fun](https://make.fun/bounty/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23) bounty entry: a program that pitches the worst app idea ever in one line.

## What it does

`main.ts` (Node 22, stdlib only) writes a single sentence — at most 240
characters — pitching the worst, most useless app imaginable to
`/output/entry.txt`.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
